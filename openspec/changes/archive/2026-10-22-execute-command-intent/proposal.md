## Why

A bare `/oc-beads:sync` returned help without attempting synchronization. The accepted correction makes the invoked workflow itself a bounded user request, including when no trailing details are supplied.

## What Changes

- Put invoked name and requested outcome before optional literal details in native prompts.
- Reconcile affected purpose and guidance authority clauses; retain real permissions, holds, inputs, modes, actor attribution and parent acceptance.
- Make ordinary sync use supported `bd sync --no-adopt` with existing configuration and honest outcomes; add concise operational guidance and seven approved primary resource remaps.
- Verify deterministic contracts and one admitted host/one genuine model through five disposable single-sample cases, reporting source and semantic gates separately.
